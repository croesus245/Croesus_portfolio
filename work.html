Selected Projects

  • FraudShield

    Fraud detection API with deployment and MLOps practices around the model. Built with Python and Flask.

    Role: builder and implementer. Result: a working API-oriented ML system.

  • SecureRAG

    Retrieval-augmented generation with security as the main constraint. Focused on safe access to generated answers and controlled retrieval patterns.

    Role: research and build. Result: a constrained RAG experiment.

  • ShiftBench

    Benchmarking research in machine learning with a focus on evaluation, comparison, and reproducibility.

    Role: research contributor. Result: a benchmarking framework for comparison work.

  • Zimbabwe Land Use Classification (live demo)

    An interactive demo of real-time land cover classification using satellite imagery and machine learning, built for evidence-based governance and SDG monitoring.

    Role: builder. Result: a working demo app. See the published research paper behind it.

  • Survey Data Validator

    A sanity-check tool for survey coordinates. Paste your points and it runs checks in parallel for duplicate point IDs, traverse closure and precision ratio, outliers, missing or zeroed coordinates, and irregular leg geometry. Computes a Bowditch adjustment, plots an interactive traverse you can zoom and measure on, and exports to JSON, CSV or PNG.

    Role: builder. Result: a working validation tool for field survey data.

  • Lagos Flood Prediction & Alert System

    A prototype flood-risk tool for Lagos, combining rainfall and elevation data per area with a risk-scoring model, an interactive risk map, and a what-if scenario simulator. Built with Streamlit and Folium. The weather feed in this version is simulated, not a live data source.

    Role: builder. Result: a working prototype, not yet connected to real weather data.

  • DevEats — Food Recommender for Developers

    A food recommender built during the TechOff hackathon, under a 45-minute time limit.

    Role: builder. Result: a hackathon build, built in under 45 minutes.

  • Location Whisperer

    A Nigerian location-coding system that turns GPS coordinates into short, shareable codes, like turning "6.5244, 3.3792" into "LA-K7P32." Includes code generation, current-location lookup, navigation by code, QR codes, and sharing.

    Role: builder. Status: in development, running locally. No production deployment yet.

Based in Nigeria.
